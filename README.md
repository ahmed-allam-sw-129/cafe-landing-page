☕ Areej Café - Landing Page

A modern and interactive responsive landing page for a specialty coffee shop, built with HTML5, CSS3, and Vanilla JavaScript without relying on heavy external frameworks to ensure optimal performance and fast load times.

🚀 Features

📱 Fully Responsive Design: Optimized for all screen sizes (Mobile, Tablet, and Desktop).

🎨 Modern UI/UX: Warm and rich aesthetic tailored to match the ambiance of specialty coffee.

🌐 RTL Support: Full Right-to-Left Arabic text layout using Google Fonts (Cairo).

🔍 Dynamic Menu Filtering: Easily filter between hot drinks, cold beverages, and desserts without reloading the page.

📱 Interactive Mobile Navigation: Smooth slide-in menu for smaller screens.

📜 Smooth Scrolling: Seamless section-to-section navigation when clicking header links.

📝 Contact & Reservation Form: Interactive form with instant feedback simulation upon submission.

🔝 Back to Top Button: Automatically appears on scroll for easy navigation.

📁 Project Structure

landing_page/
├── coffelandingpage.html   # Main HTML markup and structure
├── coffelandingpage.css    # Styles, responsive design, and themes
└── coffelandingpage.js     # Interactivity, menu filtering, and events


🛠️ Technologies Used

HTML5: Semantic structure and content.

CSS3: Custom styles, animations, Flexbox, and CSS Grid layout.

JavaScript (ES6+): Dynamic interactions, menu filtering, and event handling.

Google Fonts: Cairo for Arabic text & Playfair Display for numbers and accents.

FontAwesome v6: Icons used across navigation, features, and footer.

💻 How to Run

Clone or download the project files.

Ensure all three files remain in the same directory structure:

- coffelandingpage.html
- coffelandingpage.css
- coffelandingpage.js


Open coffelandingpage.html in any web browser (Chrome, Firefox, Edge, Safari).

📌 Page Sections

Hero Section: Engaging headline with background overlay and Call-to-Action (CTA) buttons.

About Us: Brand backstory, key features, and years of experience badge.

Menu: Catalog of drinks and desserts categorized by type with instant filtering.
